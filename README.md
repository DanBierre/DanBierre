### Hi, I'm Dan

Self-taught dev from Auckland. I make small, calm apps under my one-person studio, Soft Light Software.

**Working on**

- **Shoji** ([getshoji.app](https://getshoji.app)): a day planner for working from home. Time blocks, a focus timer that blocks distracting apps and sites, a journal, and time tracking with invoices. Out now for Windows, iPhone and Android.
- **[Recto](https://github.com/DanBierre/recto)**: a small, quiet text editor for Windows. Free and open source. [Download it here](https://github.com/DanBierre/recto/releases/latest), and pull requests are welcome.
- **Mimitori**: an app for learning Japanese. You read real Japanese, tap a word to look it up, and review it later. Still in progress.
- **[danbierre.dev](https://danbierre.dev)**: my portfolio, styled like 16mm film.

**Tools I use**

JavaScript, TypeScript, React, React Native, Electron, Expo, Astro, Vite, Tailwind CSS, Cloudflare Workers and Capacitor.
