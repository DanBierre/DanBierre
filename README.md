### Hey, I'm Dan

I'm a self-taught dev in Auckland. I make small, calm apps that do one thing well, under my one-person studio, Soft Light Software.

**What I'm working on**

- **Shoji** ([getshoji.app](https://getshoji.app)): a calm day planner for working from home. Time blocks, a focus timer that shuts distracting apps and sites, a journal, and time tracking with invoices. It's on Windows now, and iPhone's on the way.
- **[Recto](https://github.com/DanBierre/recto)**: a small, quiet text editor for Windows. It opens fast and stays out of your way. It's free and open source, so [grab it](https://github.com/DanBierre/recto/releases/latest), or chip in if you're keen.
- **Mimitori**: a Japanese study app. Read real Japanese, tap any word to see what it means, then review it later in the same app. Still cooking.
- **[danbierre.dev](https://danbierre.dev)**: my portfolio, done up like 16mm film.

**What I use**

Mostly JavaScript and TypeScript, with React, React Native, Electron, Expo, Astro, Vite, Tailwind CSS, Cloudflare Workers and Capacitor.
